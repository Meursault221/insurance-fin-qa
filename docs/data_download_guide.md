## 二、各渠道入口

### 上海证券交易所（A 股）

- 官网：https://www.sse.com.cn
- 路径：**披露 → 上市公司信息 → 定期报告**，按股票代码搜索
- 直达入口：https://www.sse.com.cn/disclosure/listedinfo/regular/
- 下载的是**简体中文**版年度报告

### 港交所披露易 HKEXnews（H 股）

- 官网：https://www.hkexnews.hk
- 路径：**披露易 → 上市公司公告 → 标题搜寻**
- 直达入口：https://www.hkexnews.hk/listedco/listconews/advancedsearch/search_active_main_c.aspx
- 搜索技巧：输入股票代码（如 `2328`），
  在"标题类别"里选 **财务报表/环境、社会及管治资料 → 年报**
- 港股年报通常是**繁体中文**版，也有英文版。
  **建议下载繁体中文版**，跟 A 股报告术语基本对得上

### 巨潮资讯网（A 股，证监会指定）

- 官网：http://www.cninfo.com.cn
- 路径：首页搜索框输入股票代码 → 选"定期报告"
- 比上交所网站好用一些，也是官方指定披露平台

### 公司官网投资者关系页

A+H 公司一般两边都发。官网有时会提供**印刷版排版更好**的 PDF。
搜索 `<公司名> 投资者关系 定期报告` 即可。

## 三、关于"2025 年年度报告"

- 现在是 2026 年 9 月，2025 年度报告（报告期截至 2025-12-31）
  应该都已经披露了，A 股一般在 2026 年 3~4 月，港股在 2026 年 4 月前后。
- 如果某家还没找到，**先不要用 2024 年的顶上**。
  要么等，要么在 `companies.yaml` 里把年份改成实际拿到的年份，
  并把 `report_name` 一起改掉（例如 "2024年年度报告"）。
  报告的年份和报告名必须一致，否则最终引用就是错的。

## 四、下载后的检查清单

对每一份 PDF：

- [ ] 打开确认是**完整版年报**，不是摘要、不是 ESG 报告、不是通函
- [ ] 确认报告期是 2025 年度（看封面）
- [ ] 确认能选中文字（不是扫描图片版）——
      滚轮缩放后文字仍清晰可复制，说明是文本版
- [ ] 按规范重命名，放进 `data/raw/`
- [ ] 把真实 URL 填进 `configs/companies.yaml` 的 `source_url`
- [ ] 核对股票代码，把 `verified` 改成 `true`

批量检查是否为扫描件：

```bash
python -m src.cli batch --no-write
```

抽取结果里如果有 `scanned_pages` 告警，说明那份是图片版，需要先 OCR。

## 五、页码说明（很重要）

很多年报的**页脚印刷页码**和 **PDF 物理页号**对不上
（封面、目录、审计报告前后的插页都会占位）。

本项目两个都存：

- `page` —— PDF 物理页号，从 1 开始。**引用时以这个为准**，因为它可复现
- `printed_page` —— 页脚上印的数字

最终回答里显示 `页码：12页` 时，指的是物理页号。
如果老师要求按报告的印刷页码，你需要额外做一次映射（目前没做）。
