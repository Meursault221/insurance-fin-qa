# web —— 问答页面（第三阶段）

**当前为空。** 第三阶段在这里实现提问 + 回答 + 来源展示。

## 计划

推荐 **Streamlit**：单文件即可成形，跟 Python 后端同进程，不用写前端。

页面要素：
- 输入框：问一个问题
- 检索：向量召回 + BM25 召回，用 RRF（倒数排名融合）合并
- 回答区：显示答案正文
- **来源区（作业硬性要求）**：每条来源显示
  ```
  公司：中国平安
  报告：2025年年度报告
  页码：第 128 页
  章节：第三节 管理层讨论与分析 > （一）主要费用情况
  ```
- 原文片段：展示命中的 chunk 全文，方便核对
- 调试面板：显示向量得分、BM25 得分、融合后排名（写测试题记录表时很有用）

## 注意

`streamlit run` 会打开浏览器。作业要求交**问答页面截图**，
截图请放在 `web/static/screenshots/`（该目录已被 .gitignore 排除 PNG，
如果截图要提交，请把 .gitignore 里那条注释掉）。
